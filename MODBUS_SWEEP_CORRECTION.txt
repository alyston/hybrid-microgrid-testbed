RECONSTRUCTION CORRECTION - TABLE 9
The archived EMS Modbus source stores Timestamp:start, and the timestamp aligns with the request in the EMS capture. The sweep boundary must therefore be last request start + last operation duration - first request start.
The historical table is reproduced by adding the FIRST operation duration instead. That convention understates the duration to the last operation's completion and overstates the subsequent gap. It is replaced in the manuscript and in reanalyze_available_evidence.py.
